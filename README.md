Progetto di tesi triennale UniFi 2025/26, avente l'obbietivo di studiare e testare un algoritmo per l'esplorazione di aree geografiche tramite una squadra di agenti mobili.

Bachelor's degree project UniFi 2025/26, aiming to study and test an exploration algorithm for geographical areas using a team of mobile agents.

---

### Istruzioni per l'uso (How to Run)
Install requirements
```bash
pip install -r requirements.txt 
```
Generate the dataset
```bash
python main.py
```
Generate graphics results
```bash
python analyze.py
```
